Snowflake + dbt build-along: chapter 1 files

Everything you need to follow chapter 1: raw CSV to a tested daily revenue mart. The data is synthetic: 500 customers and 5,000 orders in October 2026, with 12 orders written twice (5,012 rows) and 60 rows whose status is not lower case. No real people or companies.

Download everything (zip)

What's in it

  • data/orders.csv and data/customers.csv: the two raw files. To recreate them, run tests/make_data.py (Python 3, seeded, so you get the same files).
  • setup/01_snowflake_setup.sql: warehouse, database, raw tables and the transformer role. Run it once in a Snowsight worksheet as ACCOUNTADMIN.
  • setup/02_check_raw_load.sql: the four checks after loading the CSVs with Snowsight's Load Data dialog (header line treated as the header).
  • setup/profiles.example.yml: the dbt profile. Copy it to ~/.dbt/profiles.yml, outside the project.
  • shop_analytics/ (in the zip): the dbt project as it is at the end of the chapter: fixed staging model, mart, reconciliation test and the YAML tests.
  • first-draft/stg_shop__orders.sql: the first-draft staging model. Put it in place of models/staging/stg_shop__orders.sql to see the two failing tests from the first build.

Before dbt can connect: key-pair sign-in

The profile signs in with a key pair, so set one up once. Snowflake's guide: Key-pair authentication and key-pair rotation.

  1. Make a private key and its public key on your own computer, in a folder outside the project: 
    openssl genrsa 2048 | openssl pkcs8 -topk8 -inform PEM -out rsa_key.p8 -nocrypt
openssl rsa -in rsa_key.p8 -pubout -out rsa_key.pub
    (-nocrypt leaves the key unencrypted, which is fine for a trial; drop it to set a passphrase, then add private_key_passphrase to the profile from an environment variable.)
  2. In a Snowsight worksheet, register the public key on your user. Paste the key text from rsa_key.pub without the BEGIN and END lines: 
    set my_user = '"' || current_user() || '"';
alter user identifier($my_user) set rsa_public_key = 'MIIBIjANBgkqh...';
  3. Set the environment variables the profile reads: SNOWFLAKE_ACCOUNT (your account identifier), SNOWFLAKE_USER (your login name) and SNOWFLAKE_PRIVATE_KEY_PATH (the full path to rsa_key.p8).
  4. Check the connection from the project folder with dbt debug, then run dbt build.

Never commit the private key or put it in the project folder. Tested with dbt Core 1.12.6 and dbt-snowflake 1.11.6 (pip install "dbt-core==1.12.6" "dbt-snowflake>=1.11,<1.12", Python 3.10 or newer).
